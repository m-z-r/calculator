🧮 Simple Calculator Using Python

A beginner-friendly Simple Calculator built with Python that performs four basic mathematical operations: addition, subtraction, multiplication, and division. It features an interactive menu and basic error handling to make calculations easy and reliable.

✨ Features

➕ Addition of two numbers

➖ Subtraction of two numbers

✖️ Multiplication of two numbers

➗ Division with zero-division protection

🔢 Supports integers and decimal numbers

⚠️ Handles invalid numerical input

🖥️ Simple, menu-driven interface

📚 Beginner-friendly code with comments

🛠️ Technologies Used

Python 3

input() — collects user input

if-elif-else — selects the mathematical operation

float() — converts input into numbers

try-except — handles invalid numerical input

Arithmetic operators — perform calculations
